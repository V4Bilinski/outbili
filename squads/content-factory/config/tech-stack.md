# Tech Stack — Content Factory Squad

## Plataformas Alvo

| Plataforma | Formatos | Prioridade |
|-----------|---------|-----------|
| YouTube | Shorts (60s), Videos longos | Alta |
| Instagram | Reels (90s), Carrosseis, Stories | Alta |
| TikTok | Videos (24s-10min) | Alta |
| LinkedIn | Videos (90s), Carrosseis, Posts | Media |
| Twitter/X | Videos (140s), Threads | Media |

| Ferramenta | Uso |
|-----------|-----|
| CapCut | Edicao de shorts/reels |
| Canva | Carrosseis, thumbnails |
| Descript | Transcricao, edicao por texto |
| Opus Clip | Cortes automaticos de video longo |
| Capa Lendaria | Thumbnails profissionais com IA |
