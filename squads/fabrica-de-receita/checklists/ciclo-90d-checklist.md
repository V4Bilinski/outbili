# Checklist — Ciclo de 90 Dias

Validar que o ciclo de 90 dias está estruturado corretamente antes do kick-off com o cliente.

## OKRs Definidos
- [ ] Objetivo principal do ciclo definido (único e mensurável)
- [ ] Key Results escritos no formato SMART (máximo 3 KRs por objetivo)
- [ ] KRs vinculados diretamente às travas identificadas no diagnóstico
- [ ] Baseline atual registrado para cada KR
- [ ] Meta final do ciclo (90 dias) acordada com o cliente
- [ ] OKRs validados pelo agente `@growth-planner` ou `@growth-strategist`

## Sprints Semanais
- [ ] Semanas 1–4 planejadas (foco: diagnóstico aprofundado + quick wins)
- [ ] Semanas 5–8 planejadas (foco: implementação principal)
- [ ] Semanas 9–12 planejadas (foco: otimização + consolidação)
- [ ] Cada sprint com entregável claro e proprietário definido
- [ ] Dependências entre sprints mapeadas
- [ ] Buffer de 10% do tempo para imprevistos alocado

## Métricas de Acompanhamento
- [ ] Dashboard de métricas configurado (GA4, RD Station, ActiveCampaign ou equivalente)
- [ ] Frequência de coleta definida (diária, semanal, mensal)
- [ ] Alertas de desvio configurados (threshold de ±20% da meta)
- [ ] Report semanal padronizado no `growth-report-tmpl.md`
- [ ] Check-in quinzenal com cliente agendado

## Accountability
- [ ] Responsável por cada entregável definido (agente ou time do cliente)
- [ ] RACI definido para entregas críticas
- [ ] Canal de comunicação principal acordado (WhatsApp, Slack, e-mail)
- [ ] Protocolo de escalada para bloqueios definido
- [ ] Reunião de revisão mensal agendada (dias 30, 60, 90)
- [ ] Critérios de sucesso do ciclo documentados e assinados pelo cliente

## Pré-Kick-Off
- [ ] Documento do ciclo revisado pelo `@fabrica-de-receita-master`
- [ ] Recursos necessários confirmados (acesso a ferramentas, APIs, dados)
- [ ] Orçamento de mídia aprovado (se aplicável)
- [ ] Contrato / SOW assinado
