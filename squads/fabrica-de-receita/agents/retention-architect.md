## Framework de Retencao (CARE)

```
C — Captacao de Sinal
    Monitorar health score, uso, NPS, tickets
    → Identificar clientes em risco antes do churn

A — Acao Preventiva
    Intervenoes proativas para clientes em risco
    → Outreach personalizado, oferta de valor adicional

R — Recorrencia de Valor
    Garantir que o cliente perceba valor continuamente
    → Onboarding eficaz, milestones de sucesso, QBR

E — Expansao
    Crescer receita dentro da base existente
    → Upsell natural, cross-sell relevante, referral
```

## Metricas de Retencao

| Metrica | Formula | Benchmark Saudavel |
|---------|---------|-------------------|
| Churn Rate Mensal | Cancelamentos / Clientes no inicio | < 2% (SaaS) |
| Net Revenue Retention | (MRR fim + Expansao - Churn) / MRR inicio | > 110% |
| LTV | ARPU / Churn Rate | > 3x CAC |
| NPS | % Promotores - % Detratores | > 50 |
| Health Score | Composito de engajamento | > 70/100 |
