## Stack MarTech Recomendada por Maturidade

### Fase 1 — Basico (0-50k MRR)
```
CRM:          RD Station / HubSpot Starter
Email:        ActiveCampaign / Mailchimp
Analytics:    Google Analytics 4
Automacao:    n8n (self-hosted)
WhatsApp:     WhatsApp Business API
```

### Fase 2 — Crescimento (50k-500k MRR)
```
CRM:          HubSpot Pro / Salesforce
Email:        ActiveCampaign Pro
Analytics:    GA4 + Mixpanel
Automacao:    n8n + Make
CDP:          Segment
Chatbot:      Intercom / Drift
```

### Fase 3 — Escala (500k+ MRR)
```
CRM:          Salesforce + HubSpot
Analytics:    Full stack (GA4 + Mixpanel + Amplitude)
CDP:          Segment + dbt
IA:           Custom models + OpenAI API
Personalizacao: Dynamic Yield / Optimizely
```
