# Checklist de Compliance

## Privacidade e Consentimento

### Politica de Privacidade
- [ ] Politica de privacidade publicada e acessivel
- [ ] Politica menciona uso do WhatsApp como canal de comunicacao
- [ ] Politica descreve tipos de dados coletados via WhatsApp
- [ ] Politica disponivel em portugues brasileiro

### Mecanismo de Opt-in
- [ ] Opt-in implementado e documentado
- [ ] Opt-in informa claramente: nome da empresa
- [ ] Opt-in informa claramente: tipos de mensagens que serao enviadas
- [ ] Opt-in informa claramente: frequencia esperada de mensagens
- [ ] Opt-in registrado com timestamp e origem (formulario, app, presencial)
- [ ] Prova de consentimento armazenada e recuperavel

### Mecanismo de Opt-out
- [ ] Opt-out disponivel em todas as mensagens MARKETING
- [ ] Opt-out processado em ate 24 horas
- [ ] Confirmacao de opt-out enviada ao usuario
- [ ] Regras de re-engajamento respeitadas apos opt-out

---

## LGPD (Lei Geral de Protecao de Dados)

### Base Legal
- [ ] Base legal para tratamento de dados documentada (Art. 7, LGPD)
- [ ] Consentimento: livre, informado, inequivoco (se base = consentimento)
- [ ] Legitimo interesse: teste de balanceamento realizado (se base = legitimo interesse)
- [ ] Execucao contratual: vinculo com contrato documentado (se aplicavel)

### Direitos do Titular
- [ ] Canal para exercicio de direitos do titular disponivel
- [ ] Processo para exclusao de dados definido
- [ ] Processo para portabilidade de dados definido
- [ ] Processo para revogacao de consentimento definido

### Governanca
- [ ] DPO (Encarregado) designado, se exigido
- [ ] Politica de retencao de dados definida
- [ ] Transferencia internacional de dados justificada (se aplicavel)
- [ ] Registro de tratamento de dados atualizado

---

## Politicas do WhatsApp Business

### Conteudo Proibido
- [ ] Nenhum conteudo das categorias proibidas pela Meta
- [ ] Nenhuma mensagem politica ou eleitoral
- [ ] Nenhum conteudo que viole propriedade intelectual
- [ ] Nenhuma informacao financeira nao autorizada

### Qualidade e Reputacao
- [ ] Monitoramento de quality score ativo
- [ ] Alertas configurados para queda de quality score
- [ ] Plano de contingencia para status "Flagged" ou "Restricted"
- [ ] Historico de quality score documentado

### Templates
- [ ] Status de aprovacao de todos os templates rastreado
- [ ] Templates rejeitados revisados e resubmetidos (ou removidos)
- [ ] Templates pausados investigados e corrigidos
- [ ] Nenhum template com conteudo enganoso

---

## Validacao Final

### Documentacao
- [ ] Checklist completo com todas as evidencias
- [ ] Data da ultima revisao de compliance registrada
- [ ] Responsavel pela compliance identificado
- [ ] Proxima revisao agendada (recomendado: trimestral)
