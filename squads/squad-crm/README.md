# Squad CRM — Business Operations Intelligence

Squad de especialistas em CRM e operações de negócio para o Brabissimo,
núcleo de inteligência operacional da V4 Bilinski & Co.

## Visão Geral

O Squad CRM cobre o ciclo completo de negócios:

```
PRÉ-VENDAS → VENDAS → DISTRIBUIÇÃO → PRODUÇÃO → CS → MONETIZAÇÃO → FINANCEIRO
```

Cada etapa tem um agente especialista que domina as melhores práticas
de 13 plataformas do mercado (ClickUp, HubSpot, Salesforce, Pipedrive, Monday,
Ekyte, Pipefy, Bitrix24, Kommo, RD Station, Asana, Trello, Notion).

## Como Usar

### Ativar o Squad
```
@crm-master     # Orquestrador central
@sales          # Pipeline e vendas
@cs             # Customer Success
@revops         # Financeiro
@production     # Produção e demandas
@people         # Pessoas e performance
@data           # Analytics e BI
@automation     # Workflows automatizados
```

### Comandos Principais
```
*crm-status          # Visão geral de todas as áreas
*pipeline-audit      # Auditar pipeline de vendas
*health-score-audit  # Auditar health scores dos clientes
*revenue-dashboard   # Projetar dashboard financeiro
*workload-view       # Ver carga de trabalho por pessoa
*gap-analysis        # Análise de gaps vs benchmarking
```

## Benchmarking Incorporado

O squad incorpora as melhores práticas de:

- **Pipedrive**: Rotting indicators, activity-based selling, pipeline velocity
- **HubSpot**: Health Score, CS Workspace, NPS automatizado, workflow builder
- **Salesforce**: Revenue forecasting, cross-entity reporting, ACV tracking
- **ClickUp**: Hierarquia profunda, workload view, OKRs auto-tracking
- **Monday.com**: Deal-to-Project bridge, ciclo de vida RH, performance reviews
- **Ekyte**: ROI por cliente, fluxos por tipo de demanda, produção de agência
- **Pipefy**: Agentes de IA para vendas, workflows inteligentes
- **Kommo**: WhatsApp CRM, messaging-first
- **Bitrix24**: All-in-one, invoicing nativo, diretório de funcionários

Documento completo: `docs/pesquisa/benchmarking-crm-plataformas-2026.md`

## Diferenciais do Brabissimo

O que nenhuma plataforma do mercado faz e o Brabissimo fará:

1. **Vertical para franquias de marketing digital** — atende 100% do fluxo V4
2. **Deal-to-Squad bridge nativo** — fechamento vira distribuição automática
3. **ROI por cliente em tempo real** — custo operacional vs receita
4. **Health Score que considera produção** — não apenas tickets e NPS
5. **Ranking NRR integrado** — crescimento de receita por cliente
6. **Pessoas + Produção linkados** — workload conectado à performance
7. **Financeiro operacional** — lucratividade por operação em tempo real
