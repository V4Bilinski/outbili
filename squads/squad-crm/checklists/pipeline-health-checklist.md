# Pipeline Health Checklist

Validacao periodica da saude do pipeline de vendas.

## Volume & Coverage
- [ ] Pipeline value >= 3x meta de MRR mensal
- [ ] Leads entrando semanalmente (tendencia crescente)
- [ ] Distribuicao balanceada entre stages (nao acumula em um)
- [ ] Multiplos pipelines ativos (New Biz + Upsell + Renewal)

## Quality
- [ ] Lead scoring ativo e calibrado
- [ ] Rotting rate < 15% (deals sem atividade > 7d)
- [ ] Todos os deals tem proxima acao definida
- [ ] Win/loss analysis atualizada para deals fechados

## Velocity
- [ ] Sales cycle < 30 dias (media)
- [ ] Conversion rate > 20% (lead -> won)
- [ ] Show rate > 70% (agendados -> show)
- [ ] Proposal win rate > 40%

## Process
- [ ] Todos vendedores usando o pipeline
- [ ] Deals atualizados em tempo real (nao batch)
- [ ] Forecast atualizado semanalmente
- [ ] Weekly pipeline review acontecendo

## Hygiene
- [ ] Nenhum deal sem atividade > 30 dias (fechar ou reativar)
- [ ] Dados completos em todos deals (valor, contato, stage)
- [ ] Motivos de perda registrados em deals perdidos
- [ ] Pipeline limpo de deals fantasma
