# Production Quality Checklist

Validacao de qualidade da producao de demandas.

## Delivery
- [ ] SLA on-time rate > 85%
- [ ] Avg delivery time dentro do target por tipo
- [ ] Nenhuma demanda bloqueada > 3 dias sem acao
- [ ] Backlog de demandas controlado (< 2x capacity)

## Quality
- [ ] Taxa de aprovacao > 85% (primeiro envio)
- [ ] Taxa de retrabalho < 15%
- [ ] CSAT por entrega > 8.0
- [ ] Feedback do cliente documentado

## Workload
- [ ] Utilization por profissional entre 75-85%
- [ ] Nenhum profissional acima de 95% (risco de burnout)
- [ ] Nenhum profissional abaixo de 50% (ociosidade)
- [ ] Distribuicao equilibrada dentro do squad

## Process
- [ ] Todas demandas com briefing completo
- [ ] Templates de demanda atualizados
- [ ] Fluxo de aprovacao funcionando
- [ ] Time tracking ativo para todos profissionais

## Sprint
- [ ] Sprint velocity estavel ou crescente
- [ ] Burndown chart acompanhado
- [ ] Retrospectiva acontecendo
- [ ] Action items de retro sendo executados
