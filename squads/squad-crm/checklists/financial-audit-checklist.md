# Financial Audit Checklist

Auditoria financeira mensal.

## Revenue
- [ ] MRR calculado corretamente (sum de contratos ativos)
- [ ] ARR = MRR * 12
- [ ] NRR calculado com expansion, downsell e churn
- [ ] New MRR separado de Expansion MRR
- [ ] Churned MRR documentado com motivos

## Costs
- [ ] Custo por profissional atualizado
- [ ] Horas rastreadas para todos profissionais
- [ ] Custo por demanda calculado
- [ ] Overhead alocado corretamente

## Profitability
- [ ] ROI por cliente calculado (receita - custo / custo)
- [ ] Margem por squad calculada
- [ ] Clientes com margem negativa identificados
- [ ] Plano de acao para clientes nao-lucrativos

## Forecasting
- [ ] Pipeline weighted atualizado
- [ ] Forecast vs realizado do mes anterior < 20% variance
- [ ] Cash flow projetado para proximo trimestre
- [ ] Riscos financeiros documentados

## Compliance
- [ ] Todos pagamentos rastreados
- [ ] Inadimplencia < 5%
- [ ] Reembolsos processados dentro do SLA
- [ ] Tickets financeiros resolvidos no prazo
