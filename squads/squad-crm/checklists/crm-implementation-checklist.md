# CRM Implementation Checklist

Checklist master para implementar todas as melhorias do benchmarking no Brabissimo.

## Fase 1: Pipeline de Vendas (CRITICO)
- [ ] Rotting indicators visuais (deals mudam de cor por tempo sem atividade)
- [ ] Weighted forecasting por stage (probabilidade configurable)
- [ ] Activity-based selling (proxima acao visivel no card)
- [ ] Multi-pipeline support (New Biz / Upsell / Renewal)
- [ ] Pipeline velocity dashboard
- [ ] Win/loss analysis automatizada
- [ ] Lead scoring formula configurable
- [ ] Sales sequences / cadencias

## Fase 2: Deal-to-Squad Bridge (CRITICO)
- [ ] Automacao: deal ganho -> cria projeto
- [ ] Automacao: projeto criado -> aloca squad
- [ ] Automacao: squad alocado -> cria demandas iniciais
- [ ] Onboarding checklist automatizado
- [ ] Notificacoes para todas as partes

## Fase 3: Customer Success (ALTO)
- [ ] Health Score formula configuravel com pesos
- [ ] CS Workspace (dashboard do CSM com carteira)
- [ ] Board view de clientes por health flag
- [ ] NPS automatizado em milestones (30d, 90d, 180d, renewal)
- [ ] Churn early warning system
- [ ] Renewal calendar (90/60/30 dias)
- [ ] Playbooks de retencao por tipo de risco
- [ ] CSAT por entrega individual
- [ ] Expansion scoring

## Fase 4: Financeiro & RevOps (ALTO)
- [ ] MRR/ARR dashboard em tempo real com breakdown
- [ ] Revenue forecasting baseado no pipeline weighted
- [ ] ROI por cliente (receita - custo operacional)
- [ ] Custo por hora/demanda/profissional
- [ ] Budget vs realizado por cliente
- [ ] Lucratividade por squad/servico
- [ ] Churn financeiro tracking (MRR perdido)
- [ ] LTV calculation por cohort
- [ ] Financial alerts (inadimplencia, margem negativa)

## Fase 5: People & Performance (MEDIO)
- [ ] Performance review template automatizado
- [ ] Workload visual integrado com tasks e demandas
- [ ] Capacity planning
- [ ] Employee scorecard
- [ ] Onboarding automatizado por funcao
- [ ] Ranking de performance com metricas objetivas
- [ ] 1:1 meeting tracker
- [ ] Skill matrix por equipe

## Fase 6: Automacoes (MEDIO)
- [ ] Pipeline automation (stage change -> acoes)
- [ ] CS automation (health score drop -> alertas)
- [ ] Production automation (demanda criada -> auto-assign)
- [ ] Financial automation (pagamento atrasado -> ticket)
- [ ] Notification rules configuraveis por usuario
- [ ] Scheduled actions (follow-ups)
- [ ] Cross-module triggers
- [ ] Escalation rules automaticas

## Fase 7: Analytics Avancado (MEDIO)
- [ ] Dashboard customizavel por role
- [ ] Cross-entity reporting
- [ ] Drill-down em qualquer KPI
- [ ] Cohort analysis
- [ ] Executive report automatizado (PDF mensal)
- [ ] Anomaly detection
- [ ] Forecast visual com cenarios
- [ ] Role-based dashboard (CEO vs Coordenador vs Individual)
