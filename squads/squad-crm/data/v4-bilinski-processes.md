# V4 Bilinski & Co — Processos de Negócio

## Visão Geral

A V4 Bilinski & Co é uma unidade franqueada da V4 Company, rede de franquias de
marketing digital. Opera com squads especializados atendendo clientes de diversos
segmentos com serviços de marketing digital integrado.

## Ciclo Completo do Negócio

```
1. AQUISIÇÃO (Pré-Vendas)
   Lead chega → Qualificação → Score → Agendamento de reunião
   Responsável: SDR / Comercial
   Ferramentas: WhatsApp, LinkedIn, indicações

2. VENDAS (Pipeline)
   Reunião agendada → Show/No-show → Proposta → Negociação → Fechamento
   Responsável: Closer / Comercial
   Métricas: Taxa de conversão, tamanho de deal, tempo de ciclo

3. DISTRIBUIÇÃO (Deal-to-Squad)
   Deal fechado → Onboarding → Alocação de squad → Kickoff com cliente
   Responsável: Coordenador
   Métricas: Tempo de onboarding, satisfação do primeiro mês

4. PRODUÇÃO (Demandas)
   Briefing → Planejamento → Execução → Revisão → Aprovação → Entrega
   Tipos: Design (anúncios, social), Tech (LP, sites), Copy (textos, roteiros)
   Responsável: Squad (designer, gestor de tráfego, copywriter)
   Métricas: SLA, taxa de qualidade, velocity

5. CUSTOMER SUCCESS (Retenção)
   Monitoramento → Health Score → NPS → Alertas → Intervenção → Retenção
   Responsável: CSM / Coordenador
   Métricas: NRR, taxa de churn, NPS, distribuição de saúde

6. EXPANSÃO (Monetização)
   Oportunidade identificada → Proposta → Upsell/Cross-sell → Novo contrato
   Responsável: Comercial + CSM
   Métricas: MRR de expansão, taxa de upsell

7. FINANCEIRO (Revenue Ops)
   Cobrança → Pagamento → Inadimplência → Reembolso → P&L
   Responsável: Financeiro / Coordenador
   Métricas: MRR, ARR, ROI, margem, inadimplência

8. PESSOAS (Performance)
   Recrutamento → Onboarding → Desenvolvimento → Performance → Retenção
   Responsável: Coordenador / RH
   Métricas: Utilização, OKRs, DISC, engajamento
```

## Squads Típicos

| Squad | Composição | Clientes |
|-------|-----------|----------|
| Squad Alpha | 1 gestor de tráfego + 1 designer + 1 copywriter | 5-8 clientes |
| Squad Beta | 1 gestor de tráfego + 1 designer | 3-5 clientes |
| Freelancers | Pool sob demanda | Overflow |

| Gestão de Tráfego | Campanhas Meta/Google Ads | Mensal |
| Design | Criativos, social media, identidade | Mensal |
| Copywriting | Textos para ads, landing pages | Mensal |
| Tech | Landing pages, sites, integração | Por projeto |
| Consultoria | Estratégia, planejamento, mentoria | Mensal/Pontual |
